# Master LowLevel Android v1.0

Android low-level firmware analysis and recovery assistant for GitHub and Codex.

## Capabilities
Partition intelligence, sparse/raw image inspection, binary/hex analysis, AVB and boot-chain diagnostics, and chipset-specific flashing protocol analysis.

## Codex
Open this repository in Codex and work within the `master-lowlevel-android/` directory. Codex reads the scoped `AGENTS.md` instructions.

Example task: "Master LowLevel Android: inspect this firmware partition table and prepare a read-only diagnostic report."

## Safety
Read-only by default. Back up and checksum firmware before changes. Never perform destructive writes without explicit authorization and confirmation.
